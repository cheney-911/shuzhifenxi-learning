# 数值分析学习笔记

这是一个适合手机端阅读的静态学习网站。

## 上传到 GitHub

1. 解压本文件夹内容。
2. 在仓库 `https://github.com/cheney-911/shuzhifenxi-learning` 页面点击 **Add file → Upload files**。
3. 将本文件夹中的 `index.html`、`lesson1.html` 和 `style.css` 一起拖入上传区域。
4. 点击 **Commit changes**。

## 开启 GitHub Pages

进入仓库的 **Settings → Pages**：

- Source 选择 `Deploy from a branch`
- Branch 选择 `main`
- Folder 选择 `/ (root)`
- 点击 **Save**

稍等片刻后，网站地址通常为：

`https://cheney-911.github.io/shuzhifenxi-learning/`

以后每次更新，只需替换对应的 HTML 或 CSS 文件并提交即可。
